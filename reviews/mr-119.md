# MR !119 — Structural-hub percentile

## Finding 1 — Medium — Percentile ties can flag far more than the intended top decile

`src/metrics/health/god_objects.rs` computes the p90 value and flags every file whose degree is greater than or equal to that value. When a dense graph has many files tied at p90, the rule can flag a large majority—or every file—rather than the upper decile. For example, if all source files have degree 10, p90 is 10 and all are labeled structural hubs even though none dominates its peers.

Define the rule in rank space with explicit tie behavior, or require degree to be strictly above the percentile value while retaining the absolute floor.
